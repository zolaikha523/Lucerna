# Lucerna Brand Guide

**Name:** LUCERNA (Latin: lamp) · **Tagline:** From Data to Decisions

No trademark search has been made for the name or the symbol. Treat both as working identity until a search is done.

## Symbol
A rounded tile, filled with a gradient from azure to teal, holds a white "L". The foot of the L opens into a beam that
rises and widens toward a warm point of light at the upper right. The reading is that the evidence (the beam) leads
to the decision (the light). The symbol stays recognisable at 16 px: the L shape and the warm dot are the only
details, so it is not a generic chart or "AI brain" icon.

| `lucerna-symbol.svg/.png` | compact icon, collapsed sidebar, loading screen |
| `favicon.svg`, `favicon.png` (64), `favicon-32.png`, `apple-touch-icon.png` (180) | browser and device icons |

The wordmark is Inter Display SemiBold converted to outlines, so it renders the same on every machine. Keep clear space
equal to the height of the warm dot on every side. Do not recolour, stretch, add shadows or place the symbol on busy photos.

## Application colours (system A, dark navy default)
| Token | Hex | Use |
|---|---|---|
| Navy | #0A1430 / app background #070D1C → #0B1530 | canvas, sidebar |
| Azure | #2F6BFF | primary actions, focus, links |
| Teal | #16C2B0 | secondary accent, active states |
| Violet | #8B6CFF | tertiary accent |
| Spark | #FFC56B | the point of light (symbol only, sparingly in UI) |
| Slate / Mist | #5B6B85 / #9DB0CC | secondary text, tagline |
Status colours (good #22B573, warning #E0A030, critical #E5484D, info #5B8DFF) are reserved for status and always paired
with an icon or a label. The full token set (type scale, spacing, radius, elevation, motion) is in `docs/DESIGN_SYSTEM.md`.

## Organisation brands inside dashboards
Inside an organisation's dashboard, the organisation's own logo and colours lead. Lucerna's logo is never placed in an
organisation-branded dashboard header, and Lucerna never supplies or invents an organisation's logo.

## Typography
Inter (Latin UI), Vazirmatn (Dari/Pashto/Arabic), DejaVu Sans in PDF reports. All fonts are bundled with their OFL licences.

## Icons
Lucide (ISC licence), 1.8 px stroke, bundled in `lucerna/ui/static/icons`.
