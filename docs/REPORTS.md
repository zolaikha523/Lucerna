# Report Centre

## Report types
- **Quantitative** — templates for PDM, cash/MPCA, WASH, food security, needs assessment, baseline/endline, returnee
  monitoring, programme monitoring, indicator performance, general. Includes dataset overview, data quality,
  indicators, findings with charts, comparison, interpretation, conclusions, recommendations, limitations and a data dictionary.
- **Qualitative** — executive summary; background and context; methodology; detailed thematic findings with evidence
  profile and verified quotations; cross-cutting analysis; conclusions; recommendations; annexes A–F (respondent profile,
  codebook, thematic matrix, verified quotation register, source documents, limitations and QA).
- **Mixed-methods brief** — approved evidence links and integrated findings.

## Rules
- Empty methodology fields print **"Not provided"**; Lucerna never invents sample sizes, methods or recommendations.
- Quotations come only from the approved, re-verified register; contact details are redacted by default.
- Optional AI narrative (quantitative) discards any paragraph containing a number not present in the computed results.
- Every report is marked **DRAFT** until approved.

## Workflow
1. Create → fill **Content & metadata** → choose sections and add analyst text in **Sections**.
2. **Generate** a version (Word, PDF, Excel tables). Each version is kept and can be compared with another (text diff).
3. Complete the **review steps** (evidence, themes, quotations, data quality, indicators, findings, recommendations, edit).
4. A Project Manager or MEAL Manager **approves**; a final version is generated without the draft label.
   Editing after approval returns the report to draft. Downloads are audited.
