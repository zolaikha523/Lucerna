# Bundled fonts

* `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` — DejaVu fonts (Bitstream Vera / Arev derived, free license:
  https://dejavu-fonts.github.io/License.html). Used for PDF export because they include Latin and Arabic-script glyphs.
* Web UI fonts (Inter, Vazirmatn — SIL Open Font License 1.1) are in `lucerna/ui/static/fonts/` with their licenses.
